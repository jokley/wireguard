# Code-Stack

Hier ist später code-server als zentrale Entwicklungs- und Admin-Oberfläche
vorgesehen. Der Stack soll kontrollierten Zugriff auf `/home/Projects`, über
`edge-net` auf den Edge und über `ops-net` auf Raspberry-Pi-Peers erhalten.

Dieses Skeleton enthält noch keinen Service, keine Mounts, keine Ports und keine
Zugangsdaten.
